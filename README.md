# 仿微信 AI 聊天应用 (Android/Java)

基于 Android 原生开发的仿微信 UI 聊天工具。内置多厂商大语言模型接入、情绪驱动的表情包系统，以及红包、转账等微信功能界面的本地模拟。

## 功能特性

- **UI 还原**：复刻微信聊天气泡、时间分隔、底部导航，支持流式打字回复。
- **多模型支持**：内置 DeepSeek（默认）、Kimi、通义千问、OpenAI、本地 Ollama 等 14 家兼容 OpenAI 协议的厂商接口，只需配置 API Key。
- **人设与记忆**：支持自定义系统提示词（Prompt）和“AI 人生经历”注入，使对话风格更自然。
*情绪表情包**：支持为本地图片打上情绪标签，AI 会根据对话语境识别情绪并自动发送对应表情。
- **界面模拟**：实现红包、转账、朋友圈、扫一扫等页面交互（均为纯前端逻辑模拟）。

## 构建与运行

本项目已内置打包脚本，可直接编译，也可通过 termux 运行其他环境自测。
